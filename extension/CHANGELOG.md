# Changelog

## 0.3.1

- CL のホバー・定義へ移動・参照を追加(Web 版と共通)。変数(&VAR)の型と長さ・DCL の行・使っている場所、CALL のプログラム、DCLF のファイルとそのフィールド、GOTO のラベル、CALLSUBR のサブルーチン、よく使うコマンド・演算子・組み込み関数の説明
- CL でも、使用ファイル(DCLF)・呼び出しプログラム(CALL)の一覧が出るように
- 論理ファイルが PFILE(LIB/FILE) とライブラリ付きで書かれていると、元の物理ファイルが「Not Found」になっていたのを修正(Web 版と共通)
- 逆引きの CL の読み取りを、一覧・定義へ移動と同じ解析にそろえた(行末が - の継続行、文字列の中の CALL PGM(…) に対応。表示装置ファイルを DCLF で使う CL は I/O と出る)

## 0.3.0

- 逆引きの一覧を追加。開いているファイルを使っているソース(I/U/O つき。論理ファイル経由も)、開いているプログラムを呼んでいるソースを出す(Web 版と共通)
- 呼び出しプログラムの一覧を、その先の呼び出しも開けるツリーに
- 逆引きで調べるのは、使用ファイルの一覧と同じライブラリリストのライブラリ
- 索引を作っている間は、一覧の上とステータスバーに進み具合を出す
- 逆引きの索引は一覧を開いたときに作り、変わったメンバーだけ読み直す(ワークスペースごとに保存)

## 0.2.3

- VSIX に入れる README を文字だけにして、パッケージを小さくした(画面写真つきの説明は GitHub の docs/vscode.md)

## 0.2.2

- DDS の「定義へ移動」が何も返さなかったのを修正(Web 版と共通の不具合)
- DDS の説明(TEXT / COLHDG)がないとき、ホバーなどに「undefined」と出ていたのを修正(Web 版と共通)

## 0.2.1

- 全角文字を含む行も桁どおりに色分けするように(全角の文字定数より右の欄の色がずれていた)
- 使用ファイルの一覧: 説明(TEXT)がないファイルに「undefined」と出ていたのを修正。設定などに切り替えたあとも「検索中…」のままにならないように
- コマンド「DAMCO: ソース検索」に、検索するソースファイルと検索語を引数で渡せるように
- README に画面写真と、使い方・設定・困ったときの説明を追加(VSIX にも画像を含める)

## 0.2.0

- 設定 `damco.highlighting` を追加。色分けを DAMCO と IBM i Languages から選べるように(既定は auto: IBM i Languages があればそれを使う)
- IBM i Languages の言語(rpg / rpgle / cl / dds.*)のソースでも、ホバー・定義・参照・使用ファイルの一覧が動くように
- 言語はフォルダ名(damco.sourceFiles)だけで決めるように(固定のフォルダ名の割り当てを削除)

## 0.1.1

- RPG III などの固定形式で、行末に空白がない行の色分けが欄の途中で切り替わっていたのを修正(Web 版と同じく 80 桁まで埋めて色分けする)

## 0.1.0

- 最初の版。Web 版 DAMCO の言語機能(色分け・ホバー・定義・参照・折りたたみ・CodeLens)を VS Code に移植
- ライブラリリストによる参照先の検索、使用ファイル・呼び出しプログラムの一覧、ソース検索
- RPG III のインデント表示
- ソースファイル名(QRPGSRC など)を設定 `damco.sourceFiles` で変更可能に
